# Portfolio site

Files: index.html, avatar.png, config.js

## 1) Message box (Formspree)
1. Sign up at https://formspree.io with the email you want to receive messages on.
2. Create a new form and copy its URL. It looks like https://formspree.io/f/abcdwxyz
3. Open config.js and paste the URL between the quotes after `endpoint:`.
4. If Formspree asks you to confirm your email, confirm it.

## 2) Publish on GitHub Pages
1. On GitHub, create a public repository named engabdulrahman241-cmd.github.io
2. Upload index.html, avatar.png and config.js to it.
3. Repository Settings, Pages, Deploy from a branch, main, / (root), Save.
4. After a minute the site is at https://engabdulrahman241-cmd.github.io

## 3) Test
Send yourself a message from the live site and check that it arrives in Formspree and in your inbox.
